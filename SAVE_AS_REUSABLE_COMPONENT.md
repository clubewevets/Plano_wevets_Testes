# 🎨 Salvar Seção de Planos como Reusable Component no Builder.io

Este guia mostra como salvar a seção "Encontre o plano ideal para o seu pet" como um **Reusable Component** no Builder.io, para reutilizar em outros projetos.

---

## 📋 O que você vai fazer

1. ✅ Abrir o projeto no Builder.io
2. ✅ Selecionar a seção de planos
3. ✅ Salvar como "Reusable Component"
4. ✅ Importar em outro projeto
5. ✅ Usar sem escrever código!

---

## 🚀 PASSO 1: Abrir o Projeto no Builder

### 1.1 Vá para Builder.io

Acesse:
```
https://www.builder.io/
```

### 1.2 Faça login com sua conta

Use suas credenciais do Builder.

### 1.3 Localize o projeto "Plano-20Wevets-20V1"

Na lista de projetos, procure por `Plano-20Wevets-20V1`.

### 1.4 Clique para abrir

Clique no projeto para entrar.

### ✅ Resultado esperado

Você está agora no **Visual Editor** do Builder, vendo a página.

---

## 🎯 PASSO 2: Localizar a Seção de Planos

### 2.1 Procure a seção no canvas

No editor visual (central), localize:
- 📍 Seção com título **"Encontre o plano ideal para o seu pet"**
- 📍 Com toggle Mensal/Anual
- 📍 Com 3-4 cards de planos

### 2.2 Clique para selecionar

Clique **em qualquer lugar** dentro dessa seção (não em um botão, mas na área branca).

### ✅ Resultado esperado

A seção aparece com uma **borda azul/destacada** indicando seleção.

---

## ⚙️ PASSO 3: Abrir o Menu de Componente

### 3.1 Clique com botão direito

Com a seção já selecionada, clique com **botão direito do mouse** nela.

### 3.2 Ou procure opções no topo

No **painel direito** (Properties), procure por uma opção como:
- "Make Component"
- "Convert to Component"
- "Save as Component"
- Ícone de caixa/componente

### 3.3 Alternative: Menu do Builder

Se não encontrar:
1. Clique no menu **"Component"** no topo
2. Procure por **"Make Reusable"** ou **"Save as Component"**

### ✅ Resultado esperado

Um **modal/diálogo** aparece pedindo para confirmar.

---

## 📝 PASSO 4: Nomear o Componente

### 4.1 Campo de nome aparece

Um campo de texto vai aparecer com um nome padrão:
```
Section 123
ou
Untitled Component
```

### 4.2 Mude o nome para

Limpe e digite:
```
PlansSection
```

ou em português:
```
SeçãoPlanos
```

### 4.3 (Opcional) Adicione descrição

Se houver campo de descrição, adicione:
```
Seção de planos de saúde pet com toggle de período e cards responsivos
```

### 4.4 Clique em "Save" ou "Create"

Confirme a criação.

### ✅ Resultado esperado

A seção agora é um **Reusable Component**!

Você verá algo como:
```
✓ PlansSection (Component)
```

---

## 🔄 PASSO 5: Publicar o Componente

### 5.1 Procure pelo botão "Publish"

No topo do editor, procure:
- Botão **"Publish"** (verde/azul)
- Ou **"Save & Publish"**

### 5.2 Clique para publicar

Clique no botão de publicação.

### 5.3 Confirme

Um modal pode aparecer perguntando:
```
"Publish changes to live?"
```

Clique **"Publish"** ou **"Yes"**.

### ✅ Resultado esperado

Você vê uma mensagem:
```
✓ Published successfully!
```

---

## ✨ PASSO 6: Verificar no Library (Biblioteca)

### 6.1 Procure a aba "Components" ou "Library"

No painel esquerdo do Builder, procure:
- Aba **"Components"**
- Ou **"Library"**
- Ou **"Assets"**

### 6.2 Clique para abrir

Clique nessa aba.

### 6.3 Procure por "PlansSection"

Na lista, você deve ver:
```
PlansSection (Component)
```

com um ícone de caixa 📦.

### ✅ Resultado esperado

O componente agora está **disponível globalmente** no Builder!

---

## 🔗 PASSO 7: Usar em Outro Projeto

Agora você pode usar esse componente em **qualquer projeto** no Builder!

### 7.1 Abra o novo projeto

No Builder, abra:
```
emergency-page-redesign-ae5 Copy
```

(ou qualquer outro projeto)

### 7.2 Vá para o Visual Editor

Edite a página onde quer adicionar o bloco de planos.

### 7.3 Procure por "Components"

No painel esquerdo (ou superior), procure:
- Aba **"Components"**
- Ou ícone de **blocos/caixa**

### 7.4 Procure por "PlansSection"

Na biblioteca de componentes, procure:
```
PlansSection
```

### 7.5 Arraste para o canvas

Clique e arraste o componente para onde quer.

Ou simplesmente clique nele e ele será adicionado.

### 7.6 Pronto!

O componente aparece na página! 🎉

### ✅ Resultado esperado

A seção "Encontre o plano ideal para o seu pet" aparece no novo projeto, **idêntica ao original**.

---

## 🎨 PASSO 8: Customizar no Novo Projeto (Opcional)

Se você quer **adaptar** o componente apenas neste projeto (sem afetar o original):

### 8.1 Selecione o componente

Clique nele no novo projeto.

### 8.2 Procure "Detach" ou "Override"

No painel direito, você pode:
- **Override**: Mudar apenas para este projeto
- **Detach**: Converter em componente independente

### 8.3 Ou simplesmente... deixe como está!

Se quer que seja **sincronizado**, não faça nada.

Qualquer mudança no componente original será refletida aqui.

### ✅ Resultado esperado

O componente está funcional no novo projeto.

## 🐛 Troubleshooting

### Problema: Não consigo selecionar a seção

**Solução:**
1. Clique mais perto do título ou toggle
2. Se for um componente aninhado, clique no componente pai
3. Use as **setas do painel esquerdo** para expandir/selecionar

---

### Problema: "Make Component" não aparece

**Solução:**
1. Verifique se está em **edição** (não em preview)
2. Certifique-se de estar no **Visual Editor** (não no Code Editor)
3. Tente clicar em um bloco diferente (ex: o título ou toggle)
4. Procure no menu **"Element"** ou **"Component"** no topo

---

### Problema: Componente não aparece em outro projeto

**Solução:**
1. Certifique-se de que **publicou** o componente
2. Atualize a página do novo projeto (F5)
3. Se ainda não aparecer, procure em **"All Components"** (mostrar todos)
4. Verifique se o componente está **público** (não privado)

---

### Problema: Mudei o componente, mas o outro projeto não atualizou

**Solução:**
1. Publique as mudanças no projeto original
2. Atualize a página do outro projeto (F5)
3. Se usou "Override", ele não sincroniza (é independente)

## 💡 Dicas Extras

### Agrupar componentes em pastas

Se tiver muitos componentes, organize em pastas:
1. No painel de Components
2. Clique em **"Create Folder"**
3. Arraste componentes para dentro
4. Ex: `/WeVets/PlansSection`

---

### Criar variantes do componente

Você pode criar versões diferentes:
1. `PlansSection` - Original
2. `PlansSection-Compact` - Versão reduzida
3. `PlansSection-Dark` - Versão escura

---

### Documentar o componente

No Builder, você pode adicionar:
- **Descrição**: O que faz
- **Props**: Parâmetros (se for React)
- **Preview**: Imagem do componente
